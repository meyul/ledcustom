# 나만의 독서 조명 v1.6

기존 조도 센서 3개와 LED 10개의 구역별 자동 밝기 제어에, 허스키렌즈 얼굴별 설정과 자리 비움 자동 소등을 추가했습니다.

## 준비물과 적용 범위

- Raspberry Pi Pico + MicroPython, 기존 Grove 조도 센서 3개 및 RGB LED Stick
- **초대 HUSKYLENS(SEN0305 / SEN0336)의 UART 통신 기준**입니다. HUSKYLENS 2용이 아닙니다.
- 기존 센서 GP26/27/28, LED GP18 연결은 유지합니다.

## 추가 연결

전원을 끈 상태에서 연결합니다. 아래 표는 GPIO 번호입니다. 쉴드 커넥터의 실제 연결 핀을 확인하세요.

| 허스키렌즈 | Pico |
|---|---|
| T (TX) | GP1 (UART0 RX, 물리 핀 2) |
| R (RX) | GP0 (UART0 TX, 물리 핀 1) |
| - (GND) | GND |

허스키렌즈는 자체 USB 단자에 USB 전원을 공급하고, Pico와 GND를 공통 연결합니다. 이 구성에서는 허스키렌즈의 + 단자는 연결하지 않습니다. 카메라는 책상이 아니라 앉은 사람의 얼굴을 향하게 배치합니다.

## 허스키렌즈 설정과 얼굴 등록

1. 허스키렌즈 설정에서 Protocol Type을 **UART**, 통신 속도를 **9600**으로 맞춥니다.
2. Face Recognition(얼굴 인식)을 선택합니다. 프로그램도 시작/재연결 때 이 모드를 요청합니다.
3. 여러 명을 등록하려면 얼굴 인식 설정에서 **Learn Multiple**을 켭니다.
4. 얼굴을 화면에 비추고 학습 버튼으로 등록합니다. 자세한 버튼 동작은 기기 펌웨어 안내에 따릅니다.
5. 화면에 나타나는 ID1, ID2 등을 확인하고 `lamp_profiles.json`의 같은 번호에 원하는 설정을 넣습니다. 얼굴 학습 데이터는 허스키렌즈에서 관리하며, Pico에는 밝기 설정만 저장합니다.

## Pico에 넣을 파일

Thonny에서 다음 5개를 **Pico의 같은 폴더(권장: 루트)**에 저장합니다.

- `reading_lamp_v1_5.py` — 기존 조도 보정/밝기 제어 함수
- `reading_lamp_v1_6.py` — 새 실행 파일
- `huskylens_uart.py` — UART 통신
- `lamp_presence.py` — 사용자/자리 비움 판단
- `lamp_profiles.json` — 얼굴 ID별 설정

`reading_lamp_v1_6.py`를 실행하세요. 자동 부팅을 원하면 이 파일을 Pico에 `main.py`라는 이름으로 저장하세요. `reading_lamp_v1_5.py`는 이름을 유지해야 합니다.

기존 `reading_lamp_calibration.json`이 있으면 그대로 재사용합니다. 없다면 기존 방식대로 Thonny 셸에서 안내에 따라 두 번 Enter를 눌러 보정합니다. 재보정은 `reading_lamp_v1_5.py`의 `RECALIBRATE`를 잠시 True로 바꿔 실행한 뒤 다시 False로 바꿉니다.

## 개인별 밝기 설정

`lamp_profiles.json` 예시:

```json
{
  "0": {"name": "기본", "targets": [25000, 25000, 25000], "max_brightness": 15},
  "1": {"name": "사용자 1", "targets": [28000, 28000, 28000], "max_brightness": 15},
  "2": {"name": "사용자 2", "targets": [22000, 22000, 22000], "max_brightness": 12}
}
```

- `targets`: 왼쪽/가운데/오른쪽 구역의 목표 센서값입니다. **lux나 LED 출력 %가 아닙니다.** 기존 코드와 같이 값이 높을수록 더 밝은 상태를 목표로 합니다.
- `max_brightness`: 사용자별 LED 최대 출력(%). 기존 전체 제한인 15% 이하만 허용합니다.
- ID `0`은 미등록 사용자/설정 없는 사용자에게 쓰는 기본값입니다. 삭제하지 마세요.
- 위 수치는 동작 예시이며 사용자별 권장 조도를 의미하지 않습니다. 설정을 고친 뒤 프로그램을 다시 실행하세요.

## 동작 규칙

- 시작 시 기본 조도 제어를 켜고 얼굴을 기다립니다.
- 같은 얼굴 ID가 약 1초 연속 감지되면 개인 설정으로 전환합니다.
- 얼굴이 잠시 미등록 ID로 잡히면 현재 설정을 유지합니다. ID0도 얼굴이므로 소등 타이머를 갱신합니다.
- 여러 얼굴이 보이면 기존 사용자 ID가 있는 동안 유지합니다. 그렇지 않으면 화면에서 가장 크게 잡힌 얼굴을 선택합니다.
- **얼굴이 연속 60초 감지되지 않으면** 출력 목표를 0으로 바꾸고 서서히 소등합니다. 기존 15% 출력에서는 약 5초에 걸쳐 어두워집니다.
- 얼굴이 다시 보이면 즉시 자동 조절을 재개하며, 기본 설정에서 시작해 ID 확인 후 개인 설정을 적용합니다. 밝기는 급격히 뛰지 않게 기존 속도로 증가합니다.
- 소등 대기 시간은 `lamp_presence.py`의 `ABSENCE_MS = 60000`에서 변경합니다.
- 통신 실패/손상/미완성 응답은 사람이 없다는 결과와 구분합니다. 켜진 상태에서는 소등 타이머를 유예하고 기존 조도 제어를 유지합니다. 이미 소등 상태면 소등을 유지합니다. 통신은 자동으로 다시 연결합니다.

**얼굴 미감지는 실제 자리 비움의 확정 판정이 아닙니다.** 고개를 오래 숙이거나 얼굴이 가려지면 소등될 수 있습니다. 카메라 위치와 대기 시간을 실제 독서 자세에서 조정하세요. 카메라 통신이 계속 실패하면 자동 소등은 작동하지 않습니다.

## 확인 방법

실제 보드에서는 아래를 확인하세요.

1. ID1/ID2 얼굴을 차례로 보여주고 Thonny의 ID/이름/출력이 바뀌는지 확인합니다.
2. 센서 한 구역을 어둡게 하고 구역별 제어가 유지되는지 확인합니다.
3. 카메라 앞에서 잠시 고개를 숙였다가 돌아와도 바로 꺼지지 않는지 확인합니다.
4. 60초 이상 얼굴이 없는 상태에서 서서히 꺼지고, 복귀 시 다시 켜지는지 확인합니다.
5. 통신선을 분리했을 때 켜져 있던 조명이 통신 실패만으로 소등되지 않는지 확인합니다.

PC 시뮬레이션: `python -m unittest discover -s tests -v`
실제 Pico/허스키렌즈에서의 동작은 아직 검증하지 않았습니다.
